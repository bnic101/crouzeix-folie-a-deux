Numerical range

Def. Let \(\mathcal H\) be a complex Hilbert space and \(T\in\mathcal B(\mathcal H)\) a bounded operator. The numerical range of \(T\) is \[ W(T)=\{\langle Tx,x\rangle:\ x\in\mathcal H,\ \|x\|=1\}. \]

In finite dimension closed and convex (Toeplitz–Hausdorff). In infinite dimension convex, \(\overline{W(T)}\supseteq\operatorname{conv}\sigma(T)\).

Spectral sets

Def. A set \(S\subseteq\mathbb C\) is called a \(K\)-spectral set for an operator \(T\in\mathcal B(\mathcal H)\) if \[ \|p(T)\|\le K\sup_{z\in S}|p(z)|\qquad\forall\,p\in\mathbb C[z]. \] (\(S\) bounded, polynomially convex.)

von Neumann's inequality. The disc is a spectral set for any contraction: \[ \|p(T)\|\le\sup_{z\in\mathbb D}|p(z)|,\qquad \|T\|\le1. \] (Also the closed half plane if \(\operatorname{Re}T=\tfrac{T+T^*}{2}\ge0\).)

Crouzeix conjecture

Conjecture (Crouzeix 2004). Let \(T\) be a bounded operator on a Hilbert space \(\mathcal H\). The numerical range \(\overline{W(T)}\) is a \(2\)-spectral set for \(T\).

Remark. This conjectured bound is sharp: \[ W\!\begin{pmatrix}0&1\\0&0\end{pmatrix}=D(0,\tfrac12),\qquad p(z)=z, \] \[ \Big\|\begin{pmatrix}0&1\\0&0\end{pmatrix}\Big\|=1=2\cdot\tfrac12=2\sup_{D(0,1/2)}|p(z)|. \]

Antecedents.

  • von Neumann, only for contractions.
  • Okubo–Ando 1975, Berger–Stampfli 1967: the disc is a \(2\)-spectral set.

Technique. The double layer potential.

Double layer potential

Let \(\Omega\subset\mathbb C\) be an open bounded convex set with smooth boundary \(\partial\Omega\) and \(\overline{W(T)}\subset\Omega\). \(A(\Omega)\): holomorphic on \(\Omega\), continuous on \(\overline\Omega\), sup norm. \(C(\partial\Omega)\): continuous on \(\partial\Omega\), sup norm.

For \(\sigma\in\partial\Omega\) denote the outward pointing normal by \(\nu=\nu(\sigma)\), and if \(z\in\Omega\) define the double layer potential by \[ \mu(\sigma,z)=\frac{1}{2\pi}\Big(\underbrace{\frac{\nu}{\sigma-z}}_{\text{first layer}}+\underbrace{\frac{\bar\nu}{\bar\sigma-\bar z}}_{\text{second layer}}\Big)=\frac1\pi\operatorname{Re}\underbrace{\frac{\nu}{\sigma-z}}_{\text{Cauchy kernel}}. \]

\(\mu\,ds=\tfrac1\pi\,d\arg(\sigma-z)\), \(\ \mu\ge0\), \(\ \int_{\partial\Omega}\mu\,ds=2\).

Why use? The Cauchy layer leads to a bound on \(f(z)\). If we can control the conjugate we win. (Adjoint when applying functional calculus.)

Double layer potential, cont.

Let \[ C(f,T)=\frac{1}{2\pi i}\int_{\partial\Omega}f(\sigma)(\sigma-T)^{-1}\,d\sigma\in\mathcal B(\mathcal H) \] and \[ S(f,T)=C(f,T)+C(\bar f,T)^*\in\mathcal B(\mathcal H). \] By definition \(S\) is the function calculus integration against the double layer potential \(\mu(\sigma,z)\), i.e. \[ S(f,T)=\int_{\partial\Omega}f(\sigma)\,\mu(\sigma,T)\,ds. \]

Lemma (Crouzeix–Palencia 2017). For \(f\in C(\partial\Omega)\), \(\ \|S(f,T)\|=\|f(T)+C(\bar f,T)^*\|\le2\|f\|_{\partial\Omega}\).

So the question we must answer is: how does \(\|S(f,T)\|\) control \(\|f(T)\|\)? In particular, can we estimate \(C(\bar f,T)^*\) or make it vanish all together?

Positivity and the double layer formula

Consider \[ 2\Phi(f):=f(T)+C(\bar f,T)^*=f(T)+\alpha(f)(T)^*, \] where \[ \alpha(f)(z)=\frac{1}{2\pi i}\int_{\partial\Omega}\frac{\overline{f(\sigma)}}{\sigma-z}\,d\sigma. \] Note that \(\alpha:A(\Omega)\to A(\Omega)\) is antilinear and \(\alpha(1)=1\).

Positivity of \(\Phi\) says \(2\|\Phi(f)\|\le2\|f\|_{\partial\Omega}\): the result from the previous slide, found in Crouzeix–Palencia.

Scalar case: \(2\Phi(f)(z)=f(z)+\overline{\alpha(f)(z)}\). Disc: \(\alpha(f)=\overline{f(0)}\).

An alternate approach (not taken by either ChatGPT proof) is to “hack” the formula by studying extremal functions: \(f\) extremal, \(\|f(T)\|\le\|2\Phi(f)\|\), which proves Crouzeix. (Bickel, Gorkin, Greenbaum, Overton.)

Crouzeix–Palencia, \(1+\sqrt2\)

\(K=C_\Omega\), \(\|f\|\le1\), \(T=f(A)\), \(g=\alpha(f)\), \(\|g\|\le\|f\|\) (\(\Omega\) convex). \[ TT^*TT^*=T\,\big(T+g(A)^*\big)^*\,TT^*-(fgf)(A)\,T^* \] \[ K^4\le2K^3+K^2,\qquad K\le1+\sqrt2. \] (Ransford–Schwenninger)

Uses only \(\|f(A)+g(A)^*\|\le2\) and \(\|g\|\le\|f\|\). Sharp under these (Ransford–Schwenninger 2018): \[ T=\begin{pmatrix}1&1\\0&0\end{pmatrix},\qquad \Omega=D(0,\tfrac14)\cup D(1,\tfrac14), \] \(g=-f(0)\), \(-f(1)\) on the two discs; \(h=\mp1\): \(\|h(T)\|=1+\sqrt2\).

Here \(g(1)=-1\). The Cauchy transform: \(\alpha(1)=1\).

Equivalent formulation

Theorem (Twisted real part). Let \(\mathcal A\) be a unital commutative operator algebra, let \(\theta:\mathcal A\to\mathcal B(\mathcal H)\) be a bounded homomorphism and let \(\alpha:\mathcal A\to\mathcal A\) be a unital antilinear map such that the unital linear map \[ \theta_\alpha:\mathcal A\to\mathcal B(\mathcal H),\qquad a\mapsto\tfrac12\big(\theta(a)+\theta(\alpha(a))^*\big) \] is contractive. Then \(\|\theta\|\le2\).
  • Ransford–Schwenninger (2018) show that the twisted real part theorem ⇒ Crouzeix.
  • Michael Hartz (2026) proves the theorem using Jin's ChatGPT solution.

Theorem (Holomorphic → resolvent transfer). Let \(T\in\mathcal B(\mathcal H)\) with \(\sigma(T)\subset\overline{\mathbb D}\). Let \(H:\mathbb D\to\mathcal B(\mathcal H)\) be a holomorphic function such that \(H(0)=I\) and \(\operatorname{Re}H(z)\ge0\) for all \(z\in\mathbb D\). Assume that \[ H(z)-(I-zT)^{-1} \] commutes with \(T^*\) for all \(z\in\mathbb D\). Then \(\|T\|\le2\).
  • Hartz shows that holomorphic → resolvent transfer ⇒ twisted real part.
  • \(H(z)-(I-zT)^{-1}=0\): Okubo–Ando.

Proof

\(\Delta(z):=H(z)-(I-zT)^{-1}\), \(R(z):=(I-zT)^{-1}\). On \(H^2\otimes\mathcal H\): \(\operatorname{Re}M_H\ge0\), \(M_H=M_R+M_\Delta\).

\(N_W:=\{F=\sum F_nz^n:\ \sum W^nF_n=0\}\), \(\sigma(W)\subset\mathbb D\).

  • \(\Delta(z)W=W\Delta(z)\) ⇒ \(M_\Delta N_W\subset N_W\).
  • \(\Delta(0)=0\), \(\Gamma\) the kernel of \(N_W\) at \(0\) ⇒ \(\Gamma^*M_\Delta\Gamma=0\).

\(W=\tfrac12T^*\): \[ \Gamma^*(M_R+M_R^*)\Gamma=\Gamma^*(M_H+M_H^*)\Gamma\ge0. \] \(P=\sum4^{-n}T^{*n}T^n\), \(Q=\sum2^{-n}T^{*n}T^n\), \(Y=Q-P\ge\tfrac14T^*T\): \[ 4Y-YP-PY\ge0\ \Rightarrow\ P\le2I\ \Rightarrow\ T^*T\le T^*PT=4(P-I)\le4I. \]

Dilation theory

Dilation theory

Lemma (Lorist–Schwenninger, ChatGPT). Let \(\mathcal H\) be a Hilbert space and \(T\in\mathcal B(\mathcal H)\). Suppose there exists a Hilbert space \(\mathcal K\), a contraction \(Q\in\mathcal B(\mathcal K)\) and an isometry \(V\in\mathcal B(\mathcal H,\mathcal K)\) such that the operators \[ E_n:=2V^*Q^{*n}V-T^{*n},\qquad n\in\mathbb N, \] are uniformly bounded and commute with \(T\). Then \(\|T\|\le2\).
  • \(E_n=0\): \(2\)-dilation of \(T^*\), \(\|T\|\le2\).
  • \(\mathcal K=L^2(\partial\Omega,ds;\mathcal H)\), \(Vx=\tfrac1{\sqrt2}\mu(\cdot,T)^{1/2}x\), \(Q=M_f\), \(\|f\|_\infty=1\), \(T=f(A)\): \[ V^*Q^nV=\Phi(f^n),\qquad E_n=2\Phi(f^n)^*-f(A)^{*n}=\alpha(f^n)(A). \]
  • \(E_n\) commutes with \(f(A)\); \(\|E_n\|\le\|\theta\|\|\alpha\|\).

Proof

\(\kappa:=\|T\|>1\), \(T^*Tx=\kappa^2x\), \(\|x\|=1\) (ultrapower). \[ m_n:=\operatorname{Re}\langle E_nT^nx,x\rangle,\qquad u:=Q^*VTx-\kappa Vx. \] \[ \begin{aligned} \|u\|^2&\le 2\kappa^2-\kappa^3-\kappa m_1 && (n=1)\\ \kappa m_1&\ge-\frac{\|u\|^2}{(\kappa-1)^2} && (\text{telescope }\kappa m_n-m_{n+1},\ \text{all }n) \end{aligned} \] \[ \|u\|^2\big(1-(\kappa-1)^{-2}\big)\le\kappa^2(2-\kappa). \]

First line alone: \(\kappa\le1+\sqrt{1-m_1}\). \(\|\alpha\|\le1\Rightarrow m_1\ge-1\Rightarrow1+\sqrt2\). \(m_1<0\) for some \(3\times3\).

Completely bounded

Conjecture. For every \(m\ge1\) and \(F=[f_{ij}]\in M_m(A(\Omega))\), \(\ \|F(T)\|\le2\sup_{z\in\Omega}\|F(z)\|\).
  • Known: \(1+\sqrt2\) (Crouzeix–Palencia); \(2\) for discs, weighted shifts (Crouzeix–Greenbaum 2025).
  • \(M_m(A(\Omega))\) not commutative. Un, Deux need the companion to commute with \(f(T)\).
  • Crouzeix–Palencia: only \(\|\alpha\|\le1\).
